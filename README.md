# 🧠 Android Memory Matrix

An Android memory-training game where players must memorize and recreate patterns in a matrix grid.  
This project demonstrates Android game logic, interactive UI design, and user input handling.

The app challenges users to remember positions in a grid and reproduce them correctly, helping improve memory, concentration, and pattern recognition.

---

# 🚀 Overview

The **Memory Matrix** app is a simple brain-training game designed to test short-term memory and attention.

Players are briefly shown a pattern inside a matrix grid.  
After the pattern disappears, they must recreate the same pattern from memory.

The goal of this project was to practice:

• Android UI development  
• Game logic implementation  
• Handling user interaction  
• Managing dynamic grid layouts  

---

# 🎮 Gameplay

1. A matrix grid appears on the screen.
2. Certain cells briefly highlight to form a pattern.
3. The pattern disappears.
4. The player must select the same cells from memory.

Correct selections allow the player to advance to harder challenges.
